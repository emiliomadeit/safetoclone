    What the grades mean

    • A85–100Strong

      Strong in every area, no malware tricks found.

    • B70–84Probably fine

      No malware tricks, but missing some signs of a well-run project.

    • C55–69Be careful

      Something is missing or off, like no updates for a long time or poor security habits. Ask someone technical first.

    • D to Funder 55Unproven

      Nothing looks wrong, but it's too new or little-known to trust yet.

    • AnygradeDangerous

      We found tricks that malware uses. Don't download it.

    Weakest link: the overall grade can be at most one letter better than the weakest safety area (people, upkeep, security habits, malware tricks), so lots of stars can't cover for a project nobody looks after. Missing paperwork only costs points. A few more limits: an archived project gets at most a C, one with no changes for over a year or no license at most a B, and one with fewer than 50 stars at most a C (a license and a README take minutes to add). Serious warning signs cap the grade however popular the repo is.

    When the independent security check has no data for a repo, we say so and grade the other four areas.

    A score is a set of warning signs, not a guarantee. A clever attacker can pass every check. When in doubt, don't install it on a work computer, and ask your IT team.

    Questions people ask

    Does an A mean it's 100% safe?

    No. A grade is a set of warning signs, not a guarantee. An A means the project is strong in every area we check and shows none of the malware tricks we look for. A clever attacker can still pass every check, so only install what you need, and only from the official GitHub page.

    What's the difference between Unproven and Dangerous?

    Both can come with a low grade. Dangerous means we found tricks that malware uses, like asking you to turn off your antivirus. Unproven means nothing looks wrong, but the project is too new or too little-known to trust yet.

    Why can a repo with lots of stars still get a low grade?

    Stars are only one of five areas, and they can be bought. The overall grade can be at most one letter better than the weakest area, so a popular repo that nobody updates, or with poor security habits, gets a lower grade. A repo that got thousands of stars in a few days from a young account, or that asks you to turn off your antivirus, is capped at a low grade however popular it looks.

    Can a GitHub repo harm my AI assistant?

    Yes. Files like CLAUDE.md, AGENTS.md, SKILL.md or .cursorrules give instructions to AI coding tools. A malicious one can tell your AI to leak API keys or run commands without asking you. We read these files and flag the ones that try.

    Is it safe to download code from GitHub?

    Most GitHub repos are safe, but some are malware dressed up as free tools. Warning signs include requests to turn off antivirus, password-protected zip files, brand-new accounts and repos that got thousands of stars in days.

    Do you download or run the code?

    No. We only read public information: the project page, the owner's profile, the main folder, the release notes, any AI instruction files (also in hidden folders like .claude/ and .cursor/) and the independent OpenSSF Scorecard security check. Your browser asks GitHub directly.

    I already installed something marked Dangerous. What now?

    Uninstall it, run a full scan with your antivirus, and change the passwords you use on that computer, starting with email and banking. If it's a work computer, tell your IT team right away.

    Why didn't my check work?

    GitHub lets each visitor do about 8 checks an hour for free. If you hit the limit, wait a few minutes and try again. Some work networks also block GitHub, so try another connection.
