How we score

100 points, four questions

We only read public information from GitHub. We never run the code. Some warning signs are so serious they cap the score no matter how popular the repo is.

30

Do people trust it?

  • How many people starred and copied it
  • How long the owner has been on GitHub
25

Is anyone looking after it?

  • When it was last updated
  • How old it is
  • Whether it ships proper releases
15

Is it open about itself?

  • A license
  • Real instructions
  • A way to report security problems
30

Any malware tricks?

  • "Turn off your antivirus"
  • Password-protected zips, cracks, free premium
  • Fake stars, brand-new accounts
  • AI instruction files that try to hijack your assistant

A score is a set of warning signs, not a guarantee. A clever attacker can pass every check. When in doubt, don't install it on a work computer, and ask your IT team.
